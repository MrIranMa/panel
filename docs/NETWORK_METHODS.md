# روش‌های شبکه در ۲.۵.۴

## سه سطح متفاوت

1. HTTP پنل و WebSocket echo: سلامت مسیر داشبورد.
2. رادار مرورگر: سه نوبت Image + fetch، خودآزمایی TEST-NET، کف واکنش متناسب با تأخیر پایه، نامزد‌یابی با عدم قطعیت روشن. پورت‌های غیر TLS کنار گذاشته می‌شوند و تنظیمات کاربر حذف نمی‌شوند.
3. انتخاب واقعی در Xray: کانفیگ کامل با observatory و leastPing؛ HTTPS از داخل VLESS/Trojan، حداکثر چهار مقصد و سه الگوی Fragment. هنگام فعال‌بودن هر پنج دقیقه آزمون دارد و سهمیه مصرف می‌کند.

رادار فقط سرنخ می‌دهد؛ نتیجهٔ client-core به‌طور خودکار به پنل گزارش داده نمی‌شود. پنل به‌جای آن پینگ ساختگی نمی‌سازد. هیچ اسکن Worker-side جای مسیر کاربر را نگرفته است.

## مشاور

میانهٔ HTTP، jitter، درصد درخواست‌های بی‌پاسخ (نه packet loss واقعی)، echo، عبور HTTP واقعی از داخل تونل، نمونه‌های محدود انتقال و DNS بررسی می‌شوند. شکست یک وب‌سایت یا آپلود به‌تنهایی دلیل تغییر Early Data، DNS یا Fragment نیست. پیشنهاد محدود سازگاری با تأیید مدیر است. مشاهده‌های جانبی حکم قطعی فیلترینگ نیستند.
