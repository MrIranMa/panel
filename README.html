نسخهٔ ۲.۵.۸فارسی / EnglishCloudflare Workers & Pages

اتصال شما، کنترل شما

پنل مدیریتی برای ساخت، مدیریت و تحویل اتصال روی Cloudflare Workers و Pages؛ با رابط بازطراحی‌شده، حالت روشن و تاریک و پشتیبانی از موبایل.

شروع نصب ↗
01 / CONNECT

اتصال چندپروتکلی

VLESS و Trojan، لینک اختصاصی، QR و خروجی سازگار با Xray، Sing-box و Clash/Mihomo.

02 / MANAGE

مدیریت کاربران

کاربران مستقل، نمایش مصرف و اعتبار، مدیریت اشتراک و پشتیبان‌گیری.

03 / NETWORK

ابزارهای شبکه

اسکن IP و رنج، وضعیت اتصال و کشور تقریبی IPهای IPv4 و IPv6.

04 / ADVISOR

مشاور اتصال

بررسی وضعیت اتصال و پیشنهاد تنظیمات مناسب‌تر با تأیید مدیر.

05 / OUTBOUND

خروجی Worker

پشتیبانی از ProxyIP و پروکسی SOCKS5 / HTTP / HTTPS CONNECT.

06 / EXTRAS

ابزارهای تکمیلی

DNS خصوصی، پروکسی وب تلگرام و تنظیمات پیشرفتهٔ پنل.

راه‌اندازی

  1. نصب‌کننده را باز کنید و Workers یا Pages را انتخاب کنید.
  2. توکن Cloudflare را با دسترسی‌های لازم بسازید و در نصب‌کننده وارد کنید.
  3. مراحل نصب را دنبال کنید و نشانی پنل و گذرواژهٔ مدیریت را در جای امن نگه دارید.
  4. پس از نصب، توکن موقت را لغو کنید و از پنل برای ساخت کاربر و لینک اشتراک استفاده کنید.

برای نصب دستی Worker از worker-single-file.js و برای Pages از بستهٔ nightline-pages-update.zip استفاده کنید. اتصال KV با Binding به نام KV باید حفظ شود.

اطلاعات مهم

اطلاعات GeoIP تقریبی IP ورودی را نشان می‌دهد و لزوماً کشور خروجی پروکسی یا محل فیزیکی لبهٔ Cloudflare نیست. محدودیت‌های سرویس Cloudflare و شرایط استفادهٔ آن همچنان برقرار است.

برای ارتقای پروژهٔ موجود، پیش از انتشار نسخهٔ جدید پشتیبان بگیرید و فضای KV و Binding فعلی را حفظ کنید.
