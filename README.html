اتصال شما، پنل شما

پنلی برای ساخت، مدیریت و تحویل اتصال آماده روی Cloudflare Workers و Pages؛ با ظاهر روزنامه‌ای، حالت روشن و تاریک و رابط مناسب موبایل.

شروع نصب آسان ↗
01 / CONNECT

اتصال آماده برای کاربر

VLESS و Trojan، لینک اختصاصی، QR و خروجی مناسب Xray، Sing-box و Clash/Mihomo.

02 / MANAGE

مدیریت در یک صفحه

کاربران مستقل، نمایش مصرف و اعتبار، پشتیبان و بروزرسانی با نشان خودکار نسخهٔ تازه.

03 / WARP

حساب‌های WARP همین پنل

ساخت حساب برای کاربر از طریق Worker، نگه‌داری در KV همان پروژه و تحویل WireGuard یا MASQUE با H2/H3.

04 / RADAR

ابزار بررسی شبکه

اسکن IP و رنج از مسیر مرورگر، وضعیت‌های رنگی، کشور تقریبی و مشاور تنظیمات مناسب‌تر برای ایران.

05 / OUTBOUND

خروجی دلخواه Worker

ثبت IP خالی به‌عنوان ProxyIP یا استفاده از SOCKS5 و HTTP/HTTPS CONNECT؛ بدون اشتباه‌گرفتن کاربرد این دو.

06 / EXTRAS

ابزارهای همراه

DNS خصوصی، پروکسی رسمی وب تلگرام، برنامه‌های سازگار و تنظیمات پیشرفته با تأیید مدیر.

نصب در چند قدم

  1. نصب‌کننده را باز و Workers یا Pages را انتخاب کنید.
  2. با راهنمای همان صفحه توکن Cloudflare بسازید؛ توکن GitHub لازم نیست.
  3. پیشرفت و نتیجه را در همان صفحه ببینید؛ آدرس و گذرواژه را امن نگه دارید و توکن نصب را پس از پایان لغو کنید.
  4. وارد پنل شوید، کاربر بسازید و لینک اشتراک را در برنامهٔ سازگار وارد کنید.

نصب دستی Worker: worker-single-file.js · ارتقای Pages: nightline-pages-update.zip · اتصال فضای KV با نام KV لازم است.

حساب آمادهٔ WARP برای کاربر

کاربر را بالای پنل انتخاب کنید، بخش «حساب‌های WARP همین پنل» را باز کنید و پس از تأیید شرایط، حساب بسازید. سپس لینک آماده را کپی کنید. خروجی‌ها در صفحهٔ اشتراک کاربر نیز قرار می‌گیرند؛ بستن مرورگر حساب را پاک نمی‌کند.

Worker سرور ورودی WireGuard/UDP نمی‌شود. ترافیک این کانفیگ‌ها مستقیم به WARP می‌رود؛ سهمیه و انقضای Worker روی فایل صادرشده قابل اجرا نیست. H2 از TCP و WireGuard/H3 از UDP استفاده می‌کنند؛ اتصال روی همهٔ اپراتورها تضمین نمی‌شود.

پیش از استفاده بدانید

  • لینک کاربر، کلیدها و پشتیبان حساب محرمانه‌اند. کلید WARP در KV همین پروژه نگه‌داری می‌شود.
  • قبل از ارتقا پشتیبان بگیرید و همان پروژه و KV را حفظ کنید. حساب‌های WARP پشتیبان جدا دارند.
  • IP خالی، IP خروجی ثابت همهٔ سایت‌ها نمی‌سازد؛ برای آن پروکسی واقعی لازم است.
  • کشور تقریبی است و عنوان تازهٔ اشتراک به پشتیبانی برنامه هم بستگی دارد.
  • رایگان‌بودن پنل به معنی منابع نامحدود Cloudflare نیست.

رایگان، غیرتجاری و غیرقابل فروش. اعلان‌های رایگان‌بودن، مصرف و اعتبار بخشی ثابت از سرویس هستند.

گردش کار حساب آماده و خروجی MASQUE با الهام از DarknessShade / Masque-Generator ↗؛ کردیت داخل پنل نیز نمایش داده می‌شود. ایدهٔ تفکیک ProxyIP و زنجیره از BPB و راهنمای پروتکل‌ها از مستندات رسمی Xray بررسی شده است.
