در داشبورد جدید کلادفلر، اگر در بخش Workers گزینهٔ Upload assets را بزنی، کلادفلر یک ورکرِ «فقط فایل ثابت» می‌سازد و پیغام می‌دهد Variables/Bindings cannot be added to a Worker that only has static assets. برای فعال‌سازیِ پنل کاملِ NIGHTLINE (چندکاربره و بدون نیاز به متغیر محیطی):

  1. در منوی چپ کلادفلر به Storage & Databases → KV برو، دکمهٔ Create را بزن و یک فضا به نام nightline بساز.
  2. به Workers & Pages → Create برو، گزینهٔ Start with Hello World! را بزن و Deploy کن.
  3. روی دکمهٔ Edit code (بالا راست) کلیک کن، کل کد فایل worker-single-file.js را جایگزین کد قبلی کن و Deploy بزن.
  4. در صفحهٔ ورکر به Settings → Bindings → Add binding → KV namespace برو، در کادر Variable name دقیقاً بنویس KV، فضای nightline را انتخاب کن و Save بزن.
  5. همین صفحه را رفرش کن — فرم انتخاب رمز مدیر باز می‌شود و دیگر هیچ متغیری لازم نداری!
  1. In Cloudflare Dashboard, open Storage & Databases → KV → Create and name it nightline.
  2. Open Workers & Pages → Create → Start with Hello World! → Deploy (do not use Workers "Upload assets", which creates a static-only Worker).
  3. Click Edit code, paste the entire contents of worker-single-file.js, and click Deploy.
  4. Go to Settings → Bindings → Add binding → KV namespace, set Variable name to KV, select nightline, and save. Refresh this page!
